# Build & flash

With an SDK active and a `board.yaml` in place, you're ready to build.

- **Preview Build Plan** shows exactly what will be built per core — the config
  artefacts, commands, and any warnings — before anything runs.
- **Build** validates, generates the config, and compiles.
- **Flash** programs the connected device.

Build and Flash are one click away from the status bar and the **Build & Flash**
view in the ALP IDE side bar.
