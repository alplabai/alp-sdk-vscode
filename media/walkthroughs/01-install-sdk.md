# Install the Alp SDK

The **SDK Manager** lists tagged Alp SDK releases and installs the one you pick
into a local cache. The active SDK supplies the board schemas, presets, and the
build-plan emitter the extension consumes.

- Browse available releases and install one.
- Or point the extension at an SDK you already have on disk.

Once an SDK is active, `board.yaml` validation, code generation, and the build
plan all light up.
